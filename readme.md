# nvidia driver debian package

The Nvidia driver Long Term Support Branch (LTSB) previously known as Long Lived is described here: [Nvidia Driver Lifecycle](https://docs.nvidia.com/datacenter/tesla/drivers/#lifecycle)

How to install it is described in: [Nvidia Driver Installation Guide](https://docs.nvidia.com/datacenter/tesla/driver-installation-guide/latest/)

Current linux driver versions can be found on: [Nvidia Unix Driver Archive](https://www.nvidia.com/en-us/drivers/unix/)
